✅ Aclaraciones de Lucas

  1. No hay abuelita 👵❌ — fue un error del audio: dijo “bolita”. Y no es “circuito” sino “circulito”: dibujas sobre la bolita.
  2. “Bola de coloritos” 🌈 — una bolita con muchos colores.
  3. Todo pasa sobre el marcador 📷 — es AR, como el Sistema Solar.
  4. Hay un botón “Asegurar” ✓ — dibujas el número y lo confirmas con un botón para revisarlo.
  5. El nivel se elige antes de cada operación 🎚️ — no una sola vez.
